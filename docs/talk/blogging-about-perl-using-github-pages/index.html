Blogging about Perl using GitHub Pages

tutorial

Description

The Perl community needs people writing about Perl. The good news is that in 2026, setting up your own Perl blog can be surprisingly easy. GitHub Pages gives us free hosting, Jekyll gives us a simple static-site generator, and GitHub Actions can take care of publishing the site whenever we add a new post.

This will be a hands-on session. We'll start with a ready-made GitHub repository containing everything you need for a simple Perl blog. You'll make your own copy, configure it and publish it using GitHub Pages. Then we'll create a first post in Markdown and watch GitHub Actions turn it into a live website.

Along the way, we'll look at how the pieces fit together: Jekyll, themes, RSS feeds, GitHub Actions and, optionally, using your own domain name. We'll also spend some time on the other half of blogging: getting people to read what you've written, by sharing posts in places where Perl programmers — and programmers more generally — are likely to find them.

If you want to follow along, bring a laptop and a GitHub account. Or you're equally welcome just to watch and try it later.

By the end of the session, you should have everything you need to run your own Perl blog — and, if you've been following along, you may already have one.

The Perl community could always use more people writing about Perl. Maybe the next one should be you.
